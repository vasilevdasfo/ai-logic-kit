# ai-logic-kit — ИИ, который реально думает по 4 законам логики

Набор настроек для Codex, Claude Code, ChatGPT и других ИИ:

- **скилл `logic-4-laws`** — 4 закона логики (тождество, противоречие, исключённое третье, достаточное основание) в виде пошаговой проверки;
- **always-on правило** — заставляет ИИ применять скилл в каждом ответе и показывать проверку;
- **нейминг чатов и задач** — `NN/D ЦВЕТ СТАТУС ИКОНКА тема · HH:mm`;
- **формат ответа** — сначала результат, потом критика и «Куда двигаться».

## Почему «ИИ пишет, что использует скилл, а результата нет»

Три причины, и что с ними делает этот набор:

| Причина | Что происходит | Исправление |
|---|---|---|
| Скилл — просто текст-лекция | ИИ прочитал, «согласился», но не знает, *что делать* на каждом шаге | `SKILL.md` переписан в порядок действий: определения → рассуждение → противоречия → основания → да/нет |
| Скилл включается только по триггеру | В обычном вопросе ИИ его не открывает | `rules/ALWAYS_ON.md` кладётся в `AGENTS.md` / `CLAUDE.md` — эти файлы ИИ читает в **каждом** чате |
| Нет видимого результата | «Я использую логику» — проверить нельзя | В конце ответа обязательный блок `🧠 Логика:`. Нет блока — значит, не применил |

## Установка

### Codex и Claude Code (Mac / Linux)

```bash
git clone https://github.com/vasilevdasfo/ai-logic-kit.git
```

```bash
bash ai-logic-kit/install.sh
```

Скрипт:
- копирует скилл в `~/.codex/skills/` и `~/.claude/skills/`;
- добавляет блок правил в конец `~/.codex/AGENTS.md` и `~/.claude/CLAUDE.md` (старый файл сохраняется как `*.bak-ai-logic-kit`; повторный запуск не дублирует блок).

Без git: зелёная кнопка **Code → Download ZIP**, распаковать, запустить `install.sh`.

После установки — перезапустить приложение и открыть **новый** чат (старые чаты правила не перечитывают).

### ChatGPT / Venice / Claude.ai (веб)

Скопировать текст из [`chat/CUSTOM_INSTRUCTIONS.txt`](chat/CUSTOM_INSTRUCTIONS.txt):
- ChatGPT: Настройки → Персонализация → Пользовательские инструкции;
- Claude.ai: Настройки → Профиль → «What personal preferences…», или в инструкции проекта;
- Venice и другие: поле system prompt / custom instructions.

### Windows

Вручную: папку `skills/logic-4-laws` скопировать в `%USERPROFILE%\.codex\skills\`, текст `rules/ALWAYS_ON.md` вставить в конец `%USERPROFILE%\.codex\AGENTS.md`.

## Проверка, что работает

Спросите в новом чате, например: *«Стакан пустой, если в нём капля воды?»*

В конце ответа должен быть блок:

```
🧠 Логика:
• Определения: пустой — в стакане нет воды; …
• Противоречия: нет
• Да/нет: стакан пустой — нет (вода есть, но мало)
• Основания: факт — условие задачи
```

Нет блока → правила не подхватились: проверьте, что открыт новый чат, и что блок есть в конце `AGENTS.md` / `CLAUDE.md`.

## Свой исходный текст

Если у вас есть полный авторский текст про логику — положите его в `skills/logic-4-laws/references/source.md` и добавьте в `SKILL.md` строку «Перед ответом прочитай `references/source.md`». Рабочие правила в `SKILL.md` при этом остаются — ИИ нужен порядок действий, а не только лекция.

## Состав

```
skills/logic-4-laws/SKILL.md   — сам скилл
rules/ALWAYS_ON.md             — правило «всегда применять» + нейминг + формат ответа

chat/CUSTOM_INSTRUCTIONS.txt   — версия для веб-чатов
```
