# Нейминг чатов и задач

Чтобы по списку чатов сразу было видно: какой проект, в каком состоянии, о чём и когда.

## Формат

```
NN/D ЦВЕТ СТАТУС ИКОНКА тема · HH:mm
```

| Поле | Что это | Пример |
|---|---|---|
| `NN` | порядковый номер задачи за день (общий счётчик, 1, 2, 3…) | `07` |
| `D` | число месяца | `2` |
| `ЦВЕТ` | проект (см. ниже) | `🟦` |
| `СТАТУС` | состояние задачи | `▶` |
| `ИКОНКА` | один эмодзи по смыслу | `🧰` |
| `тема` | результат по-русски, 2–5 слов | `Скилл логики` |
| `HH:mm` | время старта | `14:33` |

Пример: `07/2 🟦 ▶ 🧰 Скилл логики · 14:33`

## Цвета проектов (заменить на свои)

| Цвет | Проект |
|---|---|
| 🟦 | основной бизнес |
| 🟩 | обучение / сообщество |
| 🟥 | клиенты |
| 🟨 | контент |
| 🟪 | личное |
| ⬜ | система / настройки |

## Статусы

| Знак | Значение |
|---|---|
| `▶` | в работе |
| `⏸` | ждёт (меня или другого человека) |
| `✅` | готово и проверено |
| `⛔` | заблокировано — в названии или первом сообщении указать чем |

## Правила

- Продолжение той же задачи в новом чате сохраняет её номер `NN/D`, меняется только время.
- Номер не угадывать: смотреть последний номер за день в списке чатов.
- Тема — что получится в итоге («Скилл логики»), а не процесс («разбираюсь с …»).
- Для ИИ: в начале новой задачи предложи название по этому формату; переименовывай только если пользователь не задал своё.
